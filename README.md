# STM32F103 触摸计算器

基于 STM32F103C8T6、1602 字符液晶和两颗 TTP229 电容触摸芯片的 30 键计算器。
本项目为 Comsen 实验室硬件组招新作品：硬件自行焊接并调试，固件为**裸机程序**（未使用 RTOS）。

## 硬件配置

| 项目 | 说明 |
| :--- | :--- |
| 主控 | STM32F103C8T6，64 KB Flash / 20 KB RAM |
| 显示 | 1602 字符液晶，2 行 × 16 字符，4 位数据模式 |
| 输入 | 两颗 TTP229 电容触摸芯片，共 30 个触摸按键 |
| 接口 | Type-C 供电，同时作 USB 虚拟串口（CDC） |
| 时钟 | 外部 8 MHz 晶振 ×9 = 72 MHz；USB 时钟 48 MHz |

**引脚分配**

| 信号 | 引脚 |
| :--- | :--- |
| LCD：RS / E / D4–D7 | PB10 / PB11 / PB12–PB15 |
| TTP229 A：SCL / SDO | PB6 / PB7 |
| TTP229 B：SCL / SDO | PB8 / PB9 |
| USB：D- / D+ | PA11 / PA12 |
| 状态灯 | PC13 |

**定时器**：TIM3 预分频 71，计数频率 1 MHz（1 计数 = 1 微秒），供屏幕与触摸时序做微秒延时；TIM4 作为 HAL 的毫秒时基。

## 完成情况

| 阶段 | 完成情况 | 实现方式 |
| :--- | :---: | :--- |
| 1 硬件基础 | 完成 | 焊接，万用表检查，用示例验证屏幕与按键 |
| 2 串口与显示 | 完成 | USB 配成 CDC，在接收回调里做行缓冲，收满一行上屏 |

| 5 函数扩展 | AI 完成 | SHIFT 第二层键盘，函数名整段插入，求值前翻译成引擎写法 |
| 6 自选 | AI 完成 | 秒表、开机动画（自定义字符 + 滚动）、Ans、复数显示 |

## 模块说明

**触摸读取 `Core/Src/ttp229.c`**
用 GPIO 软件模拟 TTP229 的两线时序：时钟拉低 → 延时 5 微秒 → 读数据线 → 拉高 → 延时 5 微秒，重复 16 拍得到一颗芯片的 16 位状态。两颗芯片经两张映射表把通道号翻译成 0–29 的键号，输出一个 32 位键位图。微秒延时读 TIM3 计数器，用无符号相减处理 16 位回绕。

**计算器 `Core/Src/calculator.c`、`Core/Inc/calculator.h`**
表达式以字符数组 + 长度 + 光标位置表示，采用覆盖模式编辑。合法性检查集中在写入入口（连续运算符替换、小数点唯一、开头只许负号、右括号位置限制）。求值时先把写法翻译成引擎约定的单字母格式，再调用 `calculator_evaluate()`，最后把结果格式化为屏幕可显示的字符串（自写浮点转字符串，因工程使用 newlib-nano，不支持浮点 `printf`）。

**主程序与界面 `Core/Src/main.c`**
裸机主循环：每 10 毫秒扫描按键 → 连续 3 次一致才算稳定 → 只在稳定键变化时处理一次 → 按固定优先级分发按键 → 重画两行 16 字符界面。另含三种模式（计算器 / 秒表 / 串口显示）切换、显示窗口随光标滚动、PC13 分段自检灯与心跳灯。

**串口收行 `USB_DEVICE/App/usbd_cdc_if.c`**
USB 接收回调在中断上下文中执行，只做字节入缓冲与置就绪标志；主循环通过 `CDC_TakeLine_FS()` 取出一整行并拆成两行 16 字符。串口显示与计算器界面通过 MODE 键互斥。

## 与原示例的差异

- 由 FreeRTOS 多任务改为裸机 `while (1)`，不再调用 `osKernelStart()`
- 链接列表移除 `libttp229.a`，改用自写的 `ttp229.c`
- 新增 `Core/Src/calculator.c` 与 `Core/Inc/calculator.h`，并加入 `cmake/stm32cubemx/CMakeLists.txt` 的源文件列表
- `usbd_cdc_if.c` 新增行缓冲与 `CDC_TakeLine_FS()`，移除原示例的 EXPORT 命令解析
- 引脚、时钟、USB 描述符沿用 `software.ioc`，未修改

## 编译

```bash
# 仓库根目录：安装或校验工具链（只需一次）
./setup.sh

# 编译工程
cd example
./build.sh Release
```

产物位于 `example/build/Release/`：

| 文件 | 用途 |
| :--- | :--- |
| `software.elf` | 带调试信息，调试器使用 |
| `software.hex` | 烧录用 |
| `software.bin` | 烧录用，起始地址 `0x08000000` |

工具链不在默认位置时，设置环境变量 `ARM_GNU_TOOLCHAIN_HOME` 指向其绝对路径。

## 烧录

1. ST-Link 连接 SWD：3V3 / GND / SWDIO(PA13) / SWCLK(PA14)
2. 用 STM32CubeProgrammer 打开 `software.hex` 直接下载；使用 `.bin` 时起始地址填 `0x08000000`
3. 下载完成后复位，板子开始运行

上电后现象：PC13 分段闪灯（1/2/3 次分别对应引脚、TIM3、屏幕初始化完成）→ 开机动画 → 计算器界面。

## 使用说明

| 操作 | 说明 |
| :--- | :--- |
| 数字 / `+ - * / ( ) .` | 直接输入，屏幕第一行显示表达式 |
| `=` | 求值，结果显示在第二行 |
| `AC` | 清空表达式与结果 |
| `DEL` | 删除光标前一个字符 |
| `SHIFT` | 一次性修饰键：下一次按键插入 `sin(`、`cos(`、`tan(`、`log(`、`ln(`、`^`、`pi`、`e`、`i`、`Ans` |
| `MODE` | 在 计算器 / 秒表 / 串口显示 三种模式间循环 |
| 方向键 | 移动光标（上/下 = 行首/行尾，左/右 = 逐字符） |
| 串口模式 | 电脑发送一行（回车结束，最多 32 字符），屏幕分两行显示 |

## 已知限制

- **触摸**：多键同时按下只取键号最小的一个，无组合键、无长按识别
- **计算器**：覆盖模式不能中间插入；精度 6 位小数，极大/极小数显示不下；只有 `Ans` 一个记忆变量
- **串口**：单行上限 32 字符，超出部分丢弃；发送忙时不重试，快速连续操作可能丢失若干行调试输出
- **硬件**：板子背面接近可能引发误触，测试时建议用非导电支撑物垫高
